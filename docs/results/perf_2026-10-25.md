# Scene performance, 2026-10-25

Measured on `main` at 7bd68b2 (all Sprint 1 lanes merged).

Command (from `apps/web`):

```
VITE_API_URL=http://localhost:8811 pnpm exec vite build --mode test --outDir /tmp/rec-dist
pnpm exec vite preview --outDir /tmp/rec-dist --port 4393 --strictPort
node scripts/measure-scene.mjs        # PLUMBLINE_PERF_BASE_URL overrides the URL
```

Draw calls come from `window.__plumblineScene.drawCalls` (renderer.info.render.calls with
autoReset off, so shadow passes count), exposed in dev and test builds only. Frames are the
number of rendered frames in a 2 s window after a 2.5 s settle. Viewport 1440 x 900, dpr 1.

Renderer: headless Chromium, `ANGLE (Google, Vulkan 1.3.0 (SwiftShader Device ...))`, a
software renderer. Frame rates here are a floor, not a GPU measurement.

| State | Draw calls | Frames in 2 s |
|---|---|---|
| Circuit, awaiting the first reading (probe tremor running) | 25 | 111 |
| Circuit, after the first reading (warning shown) | 27 | 113 |
| Circuit, resolved | 27 | 0 |
| Thermometer roast, awaiting | 8 | 0 |
| Landing, at rest (last rendered frame includes one-shot shadow passes) | 50 | 0 |

Budget (`.claude/rules/web-design-quality.md`): under 150 draw calls, target about 27 for the
circuit; 0 fps when idle. Both hold.

Not measured here: 60 fps on an integrated GPU in a headed browser. The scene lane reported
120 frames in 2 s on an Apple GPU (ANGLE Metal) in its own worktree; that run is not
reproduced by this file. PENDING: a headed run on a laptop with an integrated GPU.
