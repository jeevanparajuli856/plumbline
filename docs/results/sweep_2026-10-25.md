Definitions: *correct* = the run ended resolved on the true hypothesis, or ended unresolved as *indistinguishable* with the truth inside the refused class (the LED_open / LED_reversed pair counts as correct when the truth is in it); runs that end at the 12 readings limit or with no informative site left are not correct. *Resolved correct* = resolved on the true hypothesis only. *Confidently wrong* = the final top class excludes the truth and holds at least 0.9 of the belief. *Resolved* = top class mass at least 0.95 on a single-member class. A *warning* fires when P(probe off the told site) > 0.5; *warning precision* = warnings issued on a real slip / warnings issued; *slip recall* = slips that drew a warning / slips (both count the same events, so the numerators match). Only truehand issues warnings. An *out-of-model reading* is more than 5 sigma from every predicted reading the hand could reach; truehand then keeps its belief and asks for the same site again, and the reading still counts as a step.
