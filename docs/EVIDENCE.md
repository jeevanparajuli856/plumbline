# Plumbline evidence and readiness checklist

Date: 2026-10-25. This file is the source for the `/evidence` page (`EvidenceTable`). Edit it here; the page renders it.
Status values: DONE, IN PROGRESS, PENDING. Evidence is a command, a file path, a DOI or URL, or a date. If a row has
none of those, its status cannot be DONE.

Two kinds of numbers appear in this document and they are kept apart:

- **Our runs**: produced by a command in this repository and written to `docs/results/` with the git SHA and seeds, or a scratch computation reproduced in the 2026-10-25 plan and labeled "scratch".
- **The brief's expectations**: numbers from the teammate's original `handsight` run reported in `docs/brief/PLUMBLINE_BUILD.md`. They are expectations until the same experiment is re-run here. They are not shown in the UI, the video, or the pitch.

## 2. Cited studies

Citations as given in `docs/brief/PLUMBLINE_BUILD.md`. DOIs are to be added when verified; none is invented here.

1. "Say It My Way", University of Maryland, CHI 2026. 11 blind participants, 418 real interactions with Be My AI over 10 days. One participant checking bread dough broke the task into separate small questions and called that "the only way to make sure that it was 100% correct."
2. "Misfitting With AI", University of Michigan, ASSETS 2024. 26 blind adults recruited through the National Federation of the Blind. Names the users' verification work "epistemic labor." Participant 23: "sometimes I wonder whether or not the inaccuracy is really more my picture taking skills."
3. Stony Brook University, arXiv 2602.18623, February 2026. 14 blind users of AI tools report answers that "contain fabricated information, or contradict themselves and ignore instructions, which made users verify more."
4. TangibleCircuits, CHI 2020. 14 participants, 8 self-reported blind. Error identification with conventional web tutorials: 27%. Expert participant E2: "Descriptions of circuit diagrams only get you so far, you really need to see how things are put together." The paper builds tactile models of the intended circuit and does not address measurement. (AccessibleCircuits, CHI 2021, adds physical components and also does not address measurement.)
5. CircuitSense, arXiv 2509.22339. Benchmark of 8,006 circuit problems. Component detection near 100% for frontier models; derivation accuracy Gemini-2.5-Pro 19.06%, Claude-Sonnet-4 6.29%, GPT-4o 4.98%. Output impedance derivation succeeded in 8 of 100 attempts.

Participant count used in the pitch: 11 + 26 + 14 = 51 blind participants across the three AI-verification studies (1 to 3).

Forum sources quoted (not peer reviewed, quoted verbatim from retrieved threads): EEVblog 2014 thread on a talking multimeter for a blind engineer (users amyk and siggi); an AppleVis comment from 2023 on AI image description ("I have no way of knowing if the original image looks anything like this").

Nearest prior art (named in the pitch before any novelty claim): Gao et al., Mathematical Problems in Engineering, 2014 (entropy-based test point selection); sequential diagnosis with unreliable tests including a POMDP treatment, IEEE 2019; de Kleer and Williams, model-based diagnosis, 1980s.

## 4. Louisiana Center for the Blind (validation partner, PENDING)

101 South Trenton Street, Ruston, Louisiana, about 35 miles from campus. About 30 students enrolled at a time;
industrial arts is a required class, two hours a day, taught under learning shades. Staff include a Director of
Technology, a Technology Instructor, an IT Specialist and an Industrial Arts Instructor. We write to the Executive
Director first and ask to be routed; we do not contact instructors around the director. We ask for 45 minutes and
one afternoon, offer to show the students the system and leave them a copy, and call it asking for help, not a study.

What the visit produces: the measured confusion matrix (row 17 of the table) and, if time allows, fault-finding
sessions (row 18). The one result that would end the project: if measured placement accuracy is above 0.95, the
published method is already sufficient. We state this before any judge asks.

## 5. How the `/evidence` page uses this file

- Rows render in order with a badge per status; PENDING and IN PROGRESS rows are visually distinct from DONE and are never collapsed.
- The Evidence column renders commands in mono and paths as text; URLs become links.
- Figures from `docs/results/figures/*.svg` appear below the table only once the corresponding `docs/results/<name>_<date>.md` exists; a missing figure shows "not yet run" and the command.
- The dated LLM transcript renders as an exhibit (`TranscriptExhibit`) with its date and the protocol used, with no derived score.
- `?present=1` hides site chrome for recording shot 8 of `docs/VIDEO_STORYBOARD.md`.
