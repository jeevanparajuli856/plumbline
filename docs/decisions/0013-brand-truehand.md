# ADR-0013: The product is named Truehand; the mark is a braille cell that is also a breadboard

Status: accepted, 2026-10-25

## Context

The working name was Plumbline, after the plumb line, a reference you trust because it hangs true.
The team chose a public brand that says what the product protects: the hand that measures without
looking. Logo files were supplied by the team (now in `apps/web/public/brand/`).

## Decision

- **Name:** Truehand. Domain truehand.tech. Support and partnership email: support@truehand.tech
  (replaces hello@tryplumbline.tech).
- **The idea behind the mark:** a braille cell and a breadboard are the same shape. Both are grids
  of dots, read by fingertip, where every hole feels identical to the one beside it. The mark is a
  six-dot cell (two columns of three) with one dot filled and ringed in red: the hole the probe
  actually found. It is the product's claim drawn as a glyph: in a grid where every hole feels the
  same, Truehand works out which one you are touching.
- **Mark colours** come from the logo files: found dot #C0271D on light, #E8503F on dark, outline
  dots in ink. Token `--brand` (tokens.json) exists only for the mark. It is never a UI state
  colour; placement warnings keep `--warning`, which always comes with the left rule, the glyph and
  the word, so the two reds are never the only cue for anything.
- **Wordmark on the site** is live text in Fraunces 600 beside the inline SVG mark, so it follows
  the theme and stays crisp. The supplied logo SVGs set the wordmark in Inter (with Helvetica,
  Arial fallbacks); they are kept as the press-kit files. Inter as brand type is on the
  POSITIONING 4.3 banned list for the site, so a Fraunces version of the lockup is a follow-up for
  the team.
- **Landing motif:** the edge plumb line becomes the edge cell column: a vertical column of
  identical holes at the right page edge, with the ringed dot sliding to the hole that matches the
  reader's place on the page and settling as the page's belief converges. Hook names in
  UI_CONTRACT 5.3 are unchanged (`data-motion="plumb"`, `data-motion-string` = the column,
  `data-motion-bob` = the ringed dot).

## What changed and what did not

Renamed: every user-facing string (site title, meta, PWA manifest, header and footer, about and
sim copy, the API title), every doc outside `docs/brief/`, the agents, skills and rules prose,
the session briefing hook.

Kept on purpose (internal identifiers only a developer sees; renaming them costs a cross-lane
refactor and buys nothing for users): the repository directory, the Python packages `plumbline`
and `plumbline_api`, `window.__plumblineScene`, `localStorage` keys `plumbline.*`, skill and rule
file names (`plumbline-engine`, `00-plumbline.md`), CSS class names such as `barPlumbline`, the
original briefs in `docs/brief/` (read-only), and the external design canvas names "Plumbline UI
Directions" and "Plumbline UI Mockups". The 3D scene's plumb-line motif is unchanged for now.
